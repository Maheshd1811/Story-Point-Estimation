An AI-powered Agile Story Point Estimation System that uses Machine Learning to automatically estimate the complexity of software user stories from natural language requirements. The system predicts Fibonacci story points and provides the estimation through a modern web interface.

 Features
 Machine Learning-Based Estimation using a Random Forest regression model.
 Natural Language Input for entering Agile user stories or software requirements.
 Fibonacci Story Point Prediction for estimating task complexity.
 FastAPI Backend for handling prediction requests through a REST API.
 HTML/CSS Frontend
